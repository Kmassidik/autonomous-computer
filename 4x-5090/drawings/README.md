# Drawings — 4× cube sheet parts

Dimensioned flat outlines and DXF files for the laser-cut parts of the 4×
housing, generated from [`../step_models`](../step_models) with FreeCAD 1.1.4.

- **`dxf/`** — one DXF per sheet part. This is what a laser shop quotes from.
- **`*.svg`** — the same outlines with dimensions and a title block, for reading
  and printing.

Send the **DXF or STEP**, never the STL: mesh files are not accepted for flat
laser cutting.

All ten parts fit inside the common 800 mm and 1000 mm machine limits — the
largest is 606.5 × 498 mm.

See [`../assembly/README.md`](../assembly/README.md) for thicknesses, cut-path
lengths, and a correction to `Part 2 - Back`.

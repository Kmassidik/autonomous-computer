Founders Edition — the budget tier. Short, cool, and the only one of the three that fits anywhere.

Workstation Edition — 96 GB of ECC VRAM. Nearly the same body as a 5090, at several times the price.

Processor

The processor in the 4× build. Twelve cores, but 112 PCIe 5.0 lanes — which is the only number that matters here.

Memory

MEMORYDDR5-4800 ECC RDIMM

32 GB registered modules. The word that matters is RDIMM — the board will not post without it.

Motherboard

MOTHERBOARDASUS Pro WS W790E-SAGE SE

EEB workstation board. Seven PCIe 5.0 slots is why this build can run four cards without bifurcating anything.

How to use these

Every folder holds the same four files: index.html (this page's detail view), model.step (CAD at true dimensions), specs.json (machine-readable, with a verified flag per field), and sources.md (where each number came from).

Check a card fits the housingOpen housing-4x-cube--RTX5090-and-RTXPRO6000.step in FreeCAD, then File → Import the GPU model.step.
Know what is trustworthyspecs.json carries a verified boolean per field. unverified means a JEDEC/ATX standard or a modelling estimate, never a vendor figure.
Re-check a numberEach sources.md lists the exact page and what it covered. Prices and specs move; re-open before buying.
Dimensions from manufacturer specifications; see sources.md in each folder. CAD generated with FreeCAD 1.1.4 — model.step. Figures marked unverified are standards or estimates, not vendor-published.

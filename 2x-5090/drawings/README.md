# Drawings — 2× box sheet parts

Dimensioned flat outlines and DXF for the laser-cut parts of the 2× housing,
generated from [`../step_models`](../step_models) with FreeCAD 1.1.4.

- **`dxf/`** — one DXF per sheet part. This is what a laser shop quotes from.
- **`*.svg`** — the same outlines with dimensions and a title block.

Send the **DXF or STEP**, never the STL: mesh files are not accepted for flat
laser cutting.

Four parts, **73.39 m** of cut path, largest 314 × 393 mm — comfortably inside
the usual 800 mm and 1000 mm machine limits.

`Part 4 - Bottom` is 15 mm and is milling work, so it has no DXF here. See
[`../assembly/README.md`](../assembly/README.md) for the full breakdown, and for
two files in `step_models` whose names are misleading.
